# TRG555 Tax Plan

เครื่องมือจำลองการประเมินภาษีเงินได้บุคคลธรรมดา (ปีภาษี 2568 และ 2569) สำหรับวางแผนภาษีและการลงทุน สร้างด้วย [Streamlit](https://streamlit.io)

> ⚠️ เครื่องมือนี้เป็นการประมาณการเบื้องต้นเพื่อการวางแผน **ไม่ใช่คำแนะนำทางภาษีอย่างเป็นทางการ** ควรตรวจสอบกับผู้เชี่ยวชาญ/กรมสรรพากรก่อนตัดสินใจจริง

## คุณสมบัติ

- คำนวณเงินได้พึงประเมินและค่าใช้จ่ายตามมาตรา 40(1)-40(8)
- คำนวณค่าลดหย่อนครบทุกหมวด (ส่วนตัว/ครอบครัว, ประกันภัย, กองทุนเพื่อการเกษียณ, Thai ESG, เงินบริจาค, Easy E-Receipt, ค่าติดตั้งโซลาร์เซลล์ ฯลฯ) พร้อมเพดานตามกฎหมาย
- รองรับปีภาษี 2568 และ 2569 — โครงสร้างค่าลดหย่อนถาวรใช้ร่วมกัน ส่วนมาตรการกระตุ้นเศรษฐกิจที่มีกำหนดเวลา (เช่น Easy E-Receipt ปี 2569 ที่ยังไม่มีประกาศ) ควบคุมการเปิด/ปิดต่อปีผ่าน `YEAR_RULES` ใน `tax_engine.py`
- สรุปภาระภาษีตามอัตราก้าวหน้า พร้อมยอดที่ต้องชำระเพิ่ม/ขอคืน
- เครื่องมือวางแผนภาษี: หาช่องว่างที่ยังลดหย่อนได้เพิ่ม และจำลองแผนใหม่ (What-if Simulator) เทียบภาษีก่อน-หลัง

## โครงสร้างโปรเจกต์

```
app.py                # entry point, ประกอบ tabs และจัดการ session state
tax_engine.py         # ตรรกะคำนวณภาษีทั้งหมด (ค่าใช้จ่าย, ค่าลดหย่อน, ภาษี, คำแนะนำวางแผน)
tabs/
  income.py           # แท็บ 1: ข้อมูลรายได้
  deductions.py       # แท็บ 2: ค่าลดหย่อนส่วนตัว/ครอบครัว
  insurance.py        # แท็บ 3: ประกันภัย
  investments.py      # แท็บ 4: กองทุนเพื่อการเกษียณ/การลงทุน
  stimulus.py         # แท็บ 5: มาตรการกระตุ้นเศรษฐกิจ (Easy E-Receipt, โซลาร์เซลล์)
  donations.py        # แท็บ 6: เงินบริจาค
  summary.py          # แท็บ 7: รายงานสรุปผล
  planning.py         # แท็บ 8: เครื่องมือวางแผนลดหย่อนภาษี
```

## การติดตั้งและรัน

```bash
pip install -r requirements.txt
streamlit run app.py
```

## หมายเหตุการพัฒนา

- ตรรกะคำนวณภาษีทั้งหมดอยู่ใน `tax_engine.py` และไม่ผูกกับ Streamlit จึงทดสอบแยกได้โดยตรง (เช่นผ่าน `python -c` หรือ pytest)
- แต่ละแท็บใน `tabs/` มีฟังก์ชัน `render()` (หรือ `render(selected_year)` สำหรับแท็บที่ต้องรู้ปีภาษี) แก้ไข UI ของแท็บใดแท็บหนึ่งได้โดยไม่กระทบแท็บอื่น
- เพิ่มค่าลดหย่อน/มาตรการใหม่: เพิ่มค่าคงที่เพดานใน `tax_engine.py` → คำนวณใน `calculate_deductions()` และใส่ลง `breakdown` dict → เพิ่ม entry ใน `PLANNING_ITEMS`/`_room_for_item` ถ้าต้องการให้ขึ้นในตัวช่วยวางแผน → เพิ่มช่องกรอกในไฟล์ `tabs/*.py` ที่เกี่ยวข้อง ถ้าเป็นมาตรการที่มีกำหนดเวลา/ยังไม่ประกาศสำหรับบางปี ให้ควบคุมผ่าน `YEAR_RULES`
