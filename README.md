# TRG555 Tax Plan

เครื่องมือจำลองการประเมินภาษีเงินได้บุคคลธรรมดา (ปีภาษี 2568) สำหรับวางแผนภาษีและการลงทุน สร้างด้วย [Streamlit](https://streamlit.io)

> ⚠️ เครื่องมือนี้เป็นการประมาณการเบื้องต้นเพื่อการวางแผน **ไม่ใช่คำแนะนำทางภาษีอย่างเป็นทางการ** ควรตรวจสอบกับผู้เชี่ยวชาญ/กรมสรรพากรก่อนตัดสินใจจริง

## คุณสมบัติ

- คำนวณเงินได้พึงประเมินและค่าใช้จ่ายตามมาตรา 40(1)-40(8)
- คำนวณค่าลดหย่อนครบทุกหมวด (ส่วนตัว/ครอบครัว, ประกันภัย, กองทุนเพื่อการเกษียณ, Thai ESG, เงินบริจาค ฯลฯ) พร้อมเพดานตามกฎหมาย
- สรุปภาระภาษีตามอัตราก้าวหน้า พร้อมยอดที่ต้องชำระเพิ่ม/ขอคืน
- เครื่องมือวางแผนภาษี: หาช่องว่างที่ยังลดหย่อนได้เพิ่ม และจำลองแผนใหม่ (What-if Simulator) เทียบภาษีก่อน-หลัง

## โครงสร้างโปรเจกต์

```
app.py              # entry point, ประกอบ tabs และจัดการ session state
tax_engine.py        # ตรรกะคำนวณภาษีทั้งหมด (ค่าใช้จ่าย, ค่าลดหย่อน, ภาษี, คำแนะนำวางแผน)
tabs/
  income.py          # แท็บ 1: ข้อมูลรายได้
  deductions.py       # แท็บ 2: ค่าลดหย่อนส่วนตัว/ครอบครัว
  insurance.py         # แท็บ 3: ประกันและการลงทุนเพื่อการเกษียณ
  donations.py         # แท็บ 4: เงินบริจาค
  summary.py            # แท็บ 5: รายงานสรุปผล
  planning.py            # แท็บ 6: เครื่องมือวางแผนลดหย่อนภาษี
```

## การติดตั้งและรัน

```bash
pip install -r requirements.txt
streamlit run app.py
```

## หมายเหตุการพัฒนา

- ตรรกะคำนวณภาษีทั้งหมดอยู่ใน `tax_engine.py` และไม่ผูกกับ Streamlit จึงทดสอบแยกได้โดยตรง (เช่นผ่าน `python -c` หรือ pytest)
- แต่ละแท็บใน `tabs/` มีฟังก์ชัน `render()` (หรือ `render(selected_year)` สำหรับแท็บที่ต้องรู้ปีภาษี) แก้ไข UI ของแท็บใดแท็บหนึ่งได้โดยไม่กระทบแท็บอื่น
